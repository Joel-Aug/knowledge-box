About this agent

This page is a live dashboard, not the agent itself. A GitHub Actions workflow runs the actual trading engine on a schedule (every 15 minutes) against real Finnhub data, and commits the result here — so it keeps running whether or not this page is open.

Edit ai-investment-agent/agent/config.mjs in the repo and push — the next scheduled run picks it up automatically.

In the repo, open the Actions tab → AI Investment Agent Runner → Run workflow → set reset to true → Run. This wipes cash, positions, journal, and history back to a fresh start. (Only someone with write access to the repo can do this — the page itself has no button for it, on purpose, since it's a public dashboard.)
