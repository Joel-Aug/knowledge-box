Cloud Sync & Calendar

Not connected

Optional: connect a small free backend so tasks follow you across devices, plus a live calendar feed and an iPhone widget.

  1. Create a free account at cloudflare.com (no credit card needed).
  2. In the dashboard: Workers & Pages → Create → connect this GitHub repo → set the root directory to task-planner/worker → deploy.
  3. Open the new Worker → Settings → Variables: add a KV namespace binding named STATE_KV (create a new namespace), and add an environment variable SYNC_KEY set to a password you make up — mark it "Encrypt". This key is yours alone; it's never stored in the code.
  4. Copy the Worker's web address (looks like https://course-to-coo-sync.you.workers.dev) and paste it below along with the same key, then tap Connect.
